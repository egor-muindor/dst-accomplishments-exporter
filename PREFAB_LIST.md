# DST Prefab Name Reference

Full list of prefab names extracted from the game scripts of **Don't Starve Together
dedicated server build 739495** (`data/databundles/scripts.zip`, `scripts/prefabs/*.lua`),
generated 2026-07-18.

Intended as a lookup reference when picking prefabs for the world-export config
(`world_prefabs` in `modoverrides.lua`). Names are exactly what `TheSim`/`Ents` report as
`inst.prefab` and what `c_countprefabs`/`DebugSpawn` accept.

**Caveats:**

- The list includes *every* registered prefab: world entities, but also FX, placers,
  inventory icons and interface helpers. For entity counting only world entities are
  meaningful.
- Extraction is static (parses `Prefab("...")` constructors plus factory patterns like
  `MakeWarg({name = "..."})`). Verified complete against the chester_bot overworld/caves
  lists (64/64 found). A handful of exotically-constructed names could still be missing;
  the authoritative source is the `Prefabs` table on a running server:
  `for k in pairs(Prefabs) do print(k) end`.

**Regenerate** (on a machine with the DST server files):

```bash
unzip -q <serverfiles>/data/databundles/scripts.zip "scripts/prefabs/*" -d /tmp/dstscripts
python3 tools/extract_prefab_names.py /tmp/dstscripts/scripts/prefabs > prefab_names.txt
```
